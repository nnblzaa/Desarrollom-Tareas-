## Nombre del proyecto
Estilos de vida entre generaciones
## Descripción
La actividad consistió en construir una página web que compara los estilos de vida y de consumo de tres generaciones: abuelo/a, padre/madre y amigo/a. La página está publicada en GitHub Pages y conectada a un escenario de la plataforma Make llamado "Generaciones_Equipo#". La persona captura las respuestas de las tres entrevistas (8 preguntas sobre comida, ropa, electrónicos, transporte, basura, desechables, agua y qué es necesario para vivir bien) y al presionar "Comparar respuestas" la página envía los datos a Make. Un agente de IA los compara y devuelve una comparación por tema, un análisis y conclusiones sobre la sustentabilidad de los hábitos de cada generación.
## Objetivos de aprendizaje
Objetivo general. Distinguir los estilos de vida y de consumo de tres generaciones del entorno, construir sin programar una página web conectada a Make e inteligencia artificial para comparar sus respuestas, y formular conclusiones propias sobre la sustentabilidad de esos hábitos.
Con esta actividad se aprendió a:
Conectar una página web con la plataforma Make mediante un webhook personalizado (Custom webhook) para recibir datos enviados desde un formulario.
l Usar un agente de IA (Make AI Agent) con instrucciones claras para comparar respuestas y generar conclusiones sin inventar datos.
l Devolver el resultado a la página con un Webhook Response en texto plano, con los encabezados necesarios para que el navegador lo acepte.
l Publicar una página web en GitHub Pages y comprobar que funcione con datos reales.
l Interpretar el análisis de la IA con criterio propio, identificando con qué conclusiones se está de acuerdo y qué dejó fuera.
l Relacionar los hábitos de consumo de cada generación con la sustentabilidad, la Carta de la Tierra y la Agenda 21.

## Material y herramientas utilizadas
l Make (plataforma de automatización en línea) para crear el escenario con sus módulos.
l IA generativa (versión gratuita) para generar el archivo index.html de la página.
l Módulos de Make: Webhooks (Custom webhook), Make AI Agent y Webhook Response.
l GitHub y GitHub Pages para guardar y publicar la página web.
l Entrevistas a tres personas (abuelo/a, padre/madre y amigo/a) con las mismas 8 preguntas.
l Computadora con Windows, navegador web (Microsoft Edge) y conexión a internet
